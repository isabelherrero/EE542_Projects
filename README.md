# EE542 Projects
This repository contains coursework completed for EE542: Internet and Cloud Computing. The projects 
explore computer networking, cloud computing, distributed systems, Internet of Things technologies, 
and hardware-accelerated computing.

## Labs
- Lab 2: C++ UDP client-server application for transferring files over a network.
- Lab 3: Network performance experiments, data collection, and visualization of results using Python.
- Lab 4: Distributed word count, character count, and minimum/maximum analysis using Hadoop MapReduce
and Apache Spark.
- Lab 5: ThingsBoard location application that calculates a group’s center and recommends the nearest
USC library.
- Lab 6: CPU and CUDA matrix multiplication, GPU optimizations, cuBLAS, Python shared libraries, and
image convolution.
